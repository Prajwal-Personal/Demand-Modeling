Mathematical Formulations & Model Estimations

Rigorous equations, parameters, and statistical test outputs

1. Linear & Logistic Demand Models
Q_top2(P) = 0.7129 - 0.000540 * P (R² = 0.9931)
Q_logit(P) = 1 / (1 + exp(-(0.8728 - 0.002211 * P))) (R² = 0.9943)

Revenue R(P) = P * Q(P) produces optimal unconstrained price P* = ₹660.46, where Point Elasticity Ed = -1.0.

2. Econometric Discrete Choice Model (Logit)
ln(p / (1-p)) = 0.0442 - 0.120*Seniority + 0.4041*Hours
+ 0.068*Useful + 0.018*Frust - 0.034*Depend

Wald z = 3.134 for Daily Hours (p = 0.0017). Odds Ratio = exp(0.4041) = 1.498. ROC-AUC = 0.600.

3. WTP Parametric Survival Functions
Weibull: S(P) = exp(-(P / 236.13)^0.9503) (R² = 0.9312)
Log-Logistic: S(P) = 1 / (1 + (P / 134.38)^1.5573) (R² = 0.8669)

Median WTP = ₹150.00, Mean WTP = ₹235.90, Empirical Max Rev Price = ₹250.00 (49.6% penetration).

4. Customer Lifetime Value (CLV)
CLV(P) = (P - c) / (μ(P) + r)
μ(P) = 0.16 + 0.00045 * P, c = ₹40, r = 0.01

Expected subscriber duration scales from 4.9 months (₹99) to 2.3 months (₹599). Market CLV peaks at ₹499.
